# 节拍器

精简的 Web 节拍器，使用 React、TypeScript、Vite、Mantine 和 Web Audio API。

## 本地运行

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm test       # 节奏解析、Tap Tempo 与音频调度测试
npm run build # TypeScript 检查与生产构建
npm run preview
```

## 功能

- 20–300 BPM；直接输入、拖动滑块、加减按钮和键盘调速；常用 BPM 一键切换：60、72、80、90、100、120、144、160、180、200。
- 四分、八分、三连音、十六分、附点、66% Swing、五/六/七连音、二对三和 58% Swing。
- 自定义拍内细分：逗号分隔的小数或分数，例如 `1/3, 1/2, 2/3`；留空只有主拍。
- 点击测速：最近最多 6 次点击的平均间隔，超过 3.2 秒自动重新开始。
- 音量、静音、节奏预览、响应式布局、设置本地保存。
- 快捷键：Space 播放/停止；T 测速；↑↓ 调速；Shift + ↑↓ 每次 5 BPM；M 静音。输入框、滑块和按钮保留原生键盘行为。

## 音频设计

参考 NiceChord 的短促方波点击音：主拍 C5（523.25Hz，50ms）、细分 G4（392Hz，30ms），细分音量较低；加入 0.5ms 起音和 2ms 收尾以减少突兀截断。

音频引擎独立于 React，以 25ms 定时器提前安排约 100ms 的声音，实际发声由 AudioContext 时钟控制。速度和细分在下一个尚未排定的主拍生效，音量即时渐变。停止会取消所有已排定的声音；从后台恢复不会集中补播错过的节拍。视觉反馈参考音频输出时间戳，并尊重减少动态效果设置。

首次播放必须由用户操作触发。移动浏览器锁屏或系统中断可能暂停音频，第一版不承诺锁屏后台连续播放；重新点击开始即可恢复。设置仅存储在本机，不上传数据。

## 项目结构

- `src/audio/MetronomeEngine.ts`：音频时钟、调度、播放生命周期。
- `src/rhythm.ts`：细分预设、解析、测速。
- `src/settings.ts`：持久化及数据校验。
- `src/App.tsx`、`src/styles.css`：交互与响应式界面。

功能参考 [NiceChord 不啰嗦的节拍器 3.0](https://nicechord.com/metro3/)，界面与代码为独立实现。连音使用精确分数，避免截断小数引入的偏差。
